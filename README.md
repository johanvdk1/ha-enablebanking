# Enable Banking for Home Assistant

A Home Assistant custom component that connects to your bank accounts via the [Enable Banking](https://enablebanking.com) API and exposes balances and transaction totals as sensors.

## Features

- Account balance sensors per bank account
- Flexible transaction query sensors (filter by creditor, period, direction)
- Supports all Belgian and European banks via Enable Banking PSD2 API

## Installation via HACS

1. Add this repository as a custom repository in HACS
2. Install the Enable Banking integration
3. Restart Home Assistant
4. Go to Settings → Integrations → Add Integration → Enable Banking

## Configuration

You will need:
- An [Enable Banking](https://enablebanking.com) account
- Your Application ID
- Your private key (generated with openssl)
- Your sessions.json (generated by linking your bank accounts)

### Sensor configuration example

```json
[
  {
    "name": "Luminus This Year",
    "creditor": "luminus",
    "period": "year",
    "direction": "DBIT"
  },
  {
    "name": "Argenta Balance",
    "creditor": "",
    "period": "month",
    "direction": "DBIT"
  }
]
```

### Periods
- `year` — from January 1st of the current year
- `month` — from the 1st of the current month

### Direction
- `DBIT` — outgoing payments
- `CRDT` — incoming payments
